# 角色组件原图拆分包

此包是用户原图的确定性裁切，不是重绘或替换设计。所有切取区域的 RGBA 像素逐字节与原图一致。未改颜色、未放大、未做抠图修补、未重建被遮挡部分。

## 内容

- 79 个组件/合成眼 PNG：5 脸底盘、19 眼组件、6 鼻子、10 嘴、14 耳朵/头顶件、13 花纹、12 身体/装备。
- 其中 11 个眼文件为不可无损分层的合成整眼，manifest 中标记 `status: composite`；可切换表情，不能当作独立眼白或眼皮遮罩。
- `reference/`：26 个原图组合示例，只作参考，不混入组件。
- `contactsheet.png`：79 个组件的灰底总览。
- `manifest.json`：原图坐标、原尺寸、输出尺寸、alpha bbox、建议 pivot、slot、眼白/眼仁对齐信息与逐像素校验结果。
- `crop_assets.py`：可复现裁切脚本（Python 3 + Pillow）。
- 原始整张素材图尚待上传，本仓库目前不含 `source/reference.png`；现有切片的使用不依赖原图。原图 SHA-256 仍保存在 manifest 中以便后续核验。

## 眼白与眼仁独立动画

- `02_eyes/sclera_blank.png` 是原图唯一真正没有固定瞳孔的眼白：68×69，中心挂点 (34, 34.5)。左右眼都可以复用这张。
- `pupil_brown/tan/blue/green/gold.png` 是独立彩色虹膜与中心黑瞳的整体组件。`pupil_slit.png` 与 `pupil_star.png` 是独立黑色竖瞳、星形瞳。
- 将眼仁本身中心对齐眼白中心，运行时单独平移眼仁即可改变视线。建议初始缩放约 0.65，并以眼白 alpha 作裁剪；缩放只是接入建议，没有写入原 PNG。
- 原图所谓“眼白（3种）”中后两项已经画入瞳孔，保存为 `eye_baked_half_top` 和 `eye_baked_round_top`，没有冒充空白眼白。
- 心形瞳带有白色底盘，保存为 `eye_heart_baked`。8 种 `eye_shape_*` 都保留完整合成眼。半睁、眯眼、闭眼等没有独立可恢复的底层像素；本包没有擅自补画。
- 原图没有单独无白底的纯黑圆瞳。独立褐色虹膜可使用，或切换现有合成整眼；如要新增纯黑圆瞳/分层眼皮，需要另行制作。

## 挂点、成对部件与像素尺寸

- 坐标采用原图左上为原点，rect 为 `[left, top, right, bottom]`，右/下边界不包含。
- PNG 不做自动 trim。`source_crop_size` 是切取区域尺寸；`output_size` 是保留对齐后的画布尺寸。
- 兔耳、狼耳、虎耳分别拆左右，左右文件保留同一完整双耳画布及相同挂点。腮红、额纹两条、三个斑点也保留各自组的共同画布。左右指图像左右。
- 成对组件只粘贴本侧原图矩形，其余画布置透明；`source_offset_xy` 可精确复原原图位置。眉纹、叶子等连成一体的轮廓作为原图一个整体保留，不凭空恢复遮挡边缘。
- 五张脸画布分别为 113×114、112×114、113×114、113×114、114×114；原图标题虽写“固定尺寸”，实际像素并非完全相同。没有强拉伸或统一尺寸。
- pivot 是建议接入挂点，并非原作者绑定数据。脸与五官默认画布中心，头顶件默认下缘中心。应依据游戏布局进行统一世界坐标定位，不能用各 PNG 左上直接叠放。
- 头巾、兜帽以及若干装备已经带有其他颜色/填充区域；没有虚构独立层。

## 原图 alpha 品质限制

原图是 1536×1024 RGBA，alpha 最小 0、最大 254，没有 alpha=255 的像素。大量背景像素 alpha 仅 1~5，边缘包含低 alpha 的杂色 RGB；主体内部也不是严格完全不透明。灰底或普通合成显示正常，但检查原始 RGB/极低 alpha 时会看到噪点。因此本包是“保留原 alpha 的 PNG”，不能称为干净、完全修好的透明素材。

本包不阈值清理 alpha，不把主体透明度改成 255，不去色边。严格 alpha bbox 可能覆盖大部分画布，所以同时给出 `alpha_ge32_bbox_xyxy` 供观察主体范围；后者不能用于自动裁剪或替换 alpha。已人工检查总览，裁切不包含可见中文标签、框线或相邻组件。

原图分类标题存在不一致：鼻子区域后半被误标为嘴，嘴标题写 8 种但实际有 10 个候选；本包按画面实际组件盘点，保留全部。

## 复现与验证

原始整张图尚待上传；现有切片使用不依赖原图。安装 Pillow 后，如需复现，请通过 `--source` 提供你持有的原图：

    python crop_assets.py --source /path/to/original-reference.png --output ./rebuilt

脚本未提供 `--source` 时会查找同目录 `source/reference.png`；当前仓库不含该文件，因此必须显式提供原图。

脚本对每个输出中的原图矩形逐字节验证 RGBA 一致性，失败会中止；清单记录原图 SHA-256。源图及所有独立组件均未修改尺寸。contactsheet 仅为了预览缩略排版，不是交付组件。

## 最终质检

已逐一目视检查灰底、黑底、白底、棋盘底总览。长矛/匕首/项链底部标签残片及左腮红旁的邻件细条已通过收紧原图裁切矩形去除。全部79个组件的 alpha≥32 主体bbox均不接触画布边缘；105个输出的原图区域逐像素一致。详情见 `qa/validation.json` 与三张检查图。原图自身低alpha噪点仍忠实保留。
