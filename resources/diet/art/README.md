# Modular reference art

These files are unscaled crops of the user-supplied character component atlas.
Faces use centered pivots. All initial human roles share `face_human_skin.png`.
`face_tiger_orange.png` is the GoldenOrange identity; the carrot uses Orange.
Palette RGB values in the demo are labels/swatches only, never rule identifiers.

Eyes are separate `sclera_blank.png` (68×69) and `pupil_brown.png` (52×55).
The latter includes the brown iris and black pupil; the atlas does not provide a
standalone round black pupil. The demo scales the pupil smaller so it remains
inside the white. Mouths are small (47×40), medium (53×42), large (70×46).
Source alpha-edge noise is preserved, not painted over or claimed as final art.
